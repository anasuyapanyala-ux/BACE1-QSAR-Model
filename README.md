# BACE1 QSAR Model — ChEMBL to Prediction

A two-part QSAR (Quantitative Structure–Activity Relationship) pipeline for **BACE1**: from raw ChEMBL bioactivity data to molecular descriptor generation, model training, and prediction on new candidate compounds.

## Notebooks (run in this order)

### 1. `BACE1_QSAR_Pipeline_ChEMBL_to_Descriptors.ipynb`
- Loads raw ChEMBL bioactivity data (`BACE1_raw_chembl.csv`)
- Computes molecular descriptors: topological descriptors, Lipinski descriptors, QED scores
- Merges everything into `BACE1_merged_descriptors.csv` (this file is generated when you run this notebook — it is **not** included in the repo)

### 2. `BACE1_QSAR_Model_Building_and_Testing.ipynb`
- Loads `BACE1_merged_descriptors.csv` (output of notebook 1 — **run notebook 1 first**)
- Trains and evaluates regression models (Random Forest, Gradient Boosting, Linear, Ridge, Lasso)
- Predicts activity for new candidate compounds using `candidates_featurized.csv`
- Outputs `BACE1_candidate_predictions.csv`
